# Purbayan Pal - Personal Resume Website 📄✨

A sleek, responsive, and professional two-column personal resume website built with clean **HTML5** and **CSS3**. Inspired by modern executive resume layouts, this project features a clean navy & slate design system, mobile responsiveness, and print-ready PDF styling.

---

## 🚀 Live Features

- 💼 **Two-Column Resume Layout**: Clean separation of core profile data (Education, Technical Skills, Interests) and dynamic accomplishments (Career Objective, Projects, Achievements, Current Focus).
- 🖨️ **Print & PDF Optimized**: Includes custom `@media print` CSS rules so you can save or print a pixel-perfect resume directly from your browser.
- 📱 **Fully Responsive**: Fluid grid & flexbox design that adapts seamlessly to desktop monitors, tablets, and mobile smartphones.
- 🎨 **Modern Aesthetics**: Integrated Google Font (*Inter*) and Font Awesome 6 icons for clean typography and visual icons.
- 🔗 **Interactive Links**: Direct `mailto:`, `tel:`, GitHub, and LinkedIn integration.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for accessibility and clear document structure.
- **CSS3**: Custom CSS variables, Flexbox, CSS Grid, and print media queries.
- **Font Awesome 6**: Vector icons for contacts and section headers.
- **Google Fonts**: Modern *Inter* typeface.

## 💻 How to Run Locally

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Purbayan07/ResumeSite.git
   cd ResumeSite
   ```

2. **Open in Browser**
   Simply double-click `index.html` or open it in any web browser (Chrome, Edge, Firefox, Safari).

3. **Export as PDF**
   Click the **"Print / Save PDF"** button at the top of the page, or press `Ctrl + P` / `Cmd + P` and select **Save as PDF**.
